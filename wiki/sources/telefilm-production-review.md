# Telefilm Production Program — Review

## Authority and Scope

[Official source](https://telefilm.ca/en/financing/production). Official overview and document index. The program finances Canadian feature films in production/post-production through eligible Canadian audiovisual companies. It provides budget and finance-plan templates. The page routes documentaries to a separate program and displays guidelines as of October 14, 2026.
